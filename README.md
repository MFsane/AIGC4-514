# HDU 日程表 · 校园任务与时间规划助手

面向杭州电子科技大学学生的 AI 辅助日程与时间规划 Web 原型。把课程、作业、实验、竞赛与社团任务放进同一张周计划，结合空课时间生成可执行、可调整的安排。

> 杭州电子科技大学第二届 AIGC 应用创新大赛 · 创意产品原型  
> 当前版本：纯前端演示版 v1.0 · 2026-11  
> 产品官网（预留）：<https://www.myhduschedule.com>

---

## 快速开始

不需要安装依赖：

```bash
cd hdu-schedule
npm start
# 打开 http://127.0.0.1:4173
```

也可以直接双击 `index.html` 打开。建议使用本地服务器，部分浏览器对 `file://` 下的剪贴板与文件读取限制更严格。

演示账号：点击右上角「登录」→「使用演示账号一键登录」。演示账号为本地模拟，不连接任何真实账号体系。

### 部署到自定义域名

将当前 `AIGC大赛/` 目录作为静态站点部署到任意 HTTPS 托管，并把站点域名绑定为 `www.myhduschedule.com`。当前环境没有该域名的 DNS / 托管权限，因此直接访问域名会失败；本地预览请使用 `http://127.0.0.1:4173`。HDUHELP 的 API 端点会按请求 Origin 返回 CORS（已用 `http://127.0.0.1:4173` 与 `https://www.myhduschedule.com` 验证）；订阅链接若被跨域策略拦截，可下载 `.ics` 后上传。

## 核心演示路径（约 4 分钟）

1. **今日概览**：查看今天的课程/任务、本周完成率、48 小时内截止与 AI 时间洞察。
2. **同步个人课表**：进入「日程表」→「同步个人课表」。在 HDUHELP 课表页右上角「课表功能 → 订阅课表」复制订阅链接，粘贴到本应用即可读取个人课表；也可以上传 `.ics` 文件或粘贴 ICS 文本。未导入时课表保持空白，不预设任何课程，页面会引导你导入。
3. **AI 智能排版（双板块）**：左侧紫色「AI 智能排版」内有「单任务排程」与「一键整理日程」两个入口。单任务可输入「AIGC 大赛方案梳理」生成 3 个无冲突时段；一键整理会读取全部进行中任务，按课程空档、截止与优先级生成新的周计划，预览后再应用。
4. **日程表**：任务会以带左侧类型色条、右侧缩略图的方格出现；图片不会遮挡文字。点击方格可查看详情、编辑、标记完成。导入课表或排入任务后，工具栏会出现「一键清理」，清空课程与日历上的任务时间，但保留「我的任务」中的任务本身。
5. **我的任务**：搜索、按类型/优先级筛选，完成任务、归档、恢复已删除任务。
6. **主题更换**：切换晴空蓝/青柠绿/暮光紫/自定义主色；选择「奶娃黄」后页面右下角出现可跟随鼠标轻轻摆动的奶娃立绘，点击会回应。
7. **休闲时间**：切换下沙 / 绍兴 / 全部校区，调整 1–50 km 范围与类型；输入「想喝杯咖啡，安静坐一会儿」让 AI 结合空档推荐，也可以上传自己的推荐与避雷地点。推荐指数明确标注为「综合参考评分」。
8. **数据统计 / 通知中心 / 个人中心**：数据统计只保留「已完成任务」和「任务饼图」，完成任务默认 0；可绑定邮箱、设置提醒提前量、发送站内测试提醒。
9. **主页面底部「信息来源」**：查看课表、杭电 Wiki、大众点评、美团、DeepSeek、奶娃迷因资料等来源与数据口径说明。

## 已实现功能

- **登录与账号**：注册、登录、登出、演示账号、账号菜单、绑定/更换邮箱、本地资料与偏好保存。
- **日程表**：空白课表 / HDUHELP 订阅课表 / ICS 导入三种来源、一键清理日程、空课解析、周/清单双视图、周切换、今天回到本周、添加/编辑/删除日程、右侧图片、当前时间线、冲突避让。
- **AI 智能排版**：两个板块——单任务排程（类型判断、多选修正、估时与优先级建议、补充链接/图片/文字、3 个候选时段）与「一键整理日程」（读取全部进行中任务，按课程空档、截止时间、优先级重新给出最佳周计划，可预览后应用）。
- **日程提醒**：开关、10/30/60/120 分钟提前量、站内 + 邮件渠道、测试提醒、每分钟前台检查。邮件发送为演示模拟。
- **任务管理**：搜索、类型筛选、优先级筛选、排序、完成、归档、恢复、误删保留。
- **数据统计**：只保留「已完成任务」计数与「任务饼图」，默认完成任务数为 0。
- **主题系统**：4 套预设 + 自定义主色 + 图片上传（页面背景/按钮纹理）+ 可读性遮罩 + 奶娃主题互动立绘与「奶娃档案」。
- **休闲推荐**：下沙 / 绍兴校区切换、1–50 km 距离筛选、按类型筛选、类 DeepSeek 对话、综合参考评分；支持用户上传自己的推荐与避雷清单，避雷地点会自动从推荐中排除。
- **通知 / 个人中心 / 帮助反馈 / 关于合规**：完整页面与空状态。
- **导出**：`.ics` 日历、任务 `.csv`、1600 × 1000 周计划 PNG 海报。
- **响应式**：桌面优先，窄屏菜单折叠、日程表横向滚动、任务行自适应。
- **来源页面**：主页面底部固定入口，汇总全部外部信息来源与使用边界。

## 数据与 AI 使用说明（重要）

这是课程竞赛原型，不是生产系统。

- 任务、邮箱、主题、上传图片与聊天记录仅保存在浏览器 `localStorage`，不会上传服务器。
- 默认课表是**空白**，任务列表也是**空的**，不预设课程或示例任务。导入课表：在 HDUHELP 课表页右上角「课表功能 → 订阅课表」复制订阅链接，粘贴到本应用；或上传从订阅链接下载的 `.ics` 文件、粘贴 ICS 文本。
- 订阅链接可能包含访问令牌，只在本机用于解析课程，不写入 `localStorage`，也不会上传到本产品的其他服务器。由于跨站登录态限制，需要用户手动从 HDUHELP 复制一次订阅链接。
- 当前 AI 判断由**可解释的本地规则**模拟，未调用 DeepSeek 或任何外部大模型。代码中保留 `AI_ENDPOINT` 适配位。正式接入后仍应保留人工确认，并标注「AI 生成，仅供参考」。
- 推荐指数是根据距离、人均、品类与公开评价信息生成的产品内「综合参考评分」，**不是**大众点评/美团官方评分，也没有抓取平台原始数据。
- 邮箱验证码 `123456` 与邮件发送均为前端演示，不会真实发出邮件。
- 校徽为原型自制的风格化示意，不使用未经授权的官方高清视觉资产。
- 奶娃主题立绘来源于用户提供的表情包素材，并参考 [memecub 奶娃表情包](https://memecub.com/zh/tag/%E5%A5%B6%E5%A8%83) 与公开迷因资料；素材版权归原作者 / 权利人，仅用于非商业课程原型。
- 地图、天气、商家距离与评分均为演示数据；课程只来自你主动导入的课表。

更完整的来源清单见应用内「信息来源」页面。

## 技术说明与扩展位

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤，便于课程演示与迭代。
- 状态集中在 `state` 对象，持久化键为 `hdu_schedule_prototype_v2`。
- 路由为轻量 hash 路由：`#overview`、`#schedule`、`#leisure`、`#sources` 等。
- 主题基于 CSS 自定义属性（`--primary`、`--primary-rgb` 等），预设与自定义颜色共用同一套视觉变量。
- AI 排程入口：`detectTaskType()`、`estimateDuration()`、`buildAISchedule()`。接入真实模型时，把「规则判断」替换为带超时/重试的 API 调用，并继续保持返回结构 `{ type, confidence, reason, duration }` 与 `{ slots, duration, conflictNote }`。
- 课表入口：`fetchIcsUrl()` / `parseICSClasses()` 负责订阅链接与 ICS 解析；`demoClasses()` 是演示回退。
- 导出：`exportICS()` / `exportCSV()` / `exportPNG()`。
- 可访问性：图标按钮具备 `aria-label`，弹窗使用 `role="dialog"` 与焦点管理，表单有显式 label；颜色对比度按蓝白默认主题设计。

### 接入真实服务前需要补齐

1. 账号体系与服务端存储（当前为本地模拟）。
2. HDUHELP 订阅链接的自动更新、过期处理与跨域失败兜底（当前由用户手动导入链接 / ICS）。
3. DeepSeek API Key 的服务端保管、超时重试、内容安全与人工确认节点。
4. 邮件服务（SMTP / 第三方）与用户明确授权、退订机制。
5. 图片上传的对象存储、大小/类型校验与服务端病毒扫描。
6. 第三方数据授权与「综合参考评分」算法口径公示。

## 已知边界

- 前台提醒检查只在页面打开时运行，关闭页面不会触发；正式版需要服务端定时任务。
- HDUHELP 同步需要手动复制一次「订阅课表」链接；页面不保存订阅链接，因此重新导入时需再次粘贴。若 HDUHELP 调整订阅或 CORS 策略，可改用 `.ics` 文件导入。
- 本地 `localStorage` 容量有限，上传图片会自动压缩，但大量图片仍可能超出容量。
- 登录密码没有真实后端校验，仅用于交互演示，请勿输入真实密码。
- 商家评分与休闲距离为演示数据；任务来自你的输入，课程只来自你主动导入的课表。不应作为真实选课、消费或出行决策依据。
